# POE Tools

面向《流放之路》简体中文客户端的 Windows 桌面工具，提供花园工艺、普通通货流程、批量洗地图、国服标价补丁和客户端增强。自动化部分通过剪贴板读取物品文本，结合 WGC 截图、OpenCV 模板匹配和 Win32 定向输入工作。

> **风险提示：** 自动化及客户端资源修改可能违反《流放之路》用户协议，存在封号或客户端损坏风险。本项目仅供学习交流，使用前请自行评估并备份重要数据。

## 功能概览

当前界面按以下页面组织：

| 页面 | 功能 | 主要准备 |
| --- | --- | --- |
| 花园工艺 | 重复执行游戏内已选中的花园工艺，读取装备并按规则停止 | `craft_button.png`、`item_slot.png` |
| 普通工艺 | 多步骤通货流程；支持前置/后置判断、分支、跳转和循环 | `item_slot.png`、仓库「非绑定 / 通用」通货页 |
| 洗地图 | 背包 5×12 格批量点金/重铸或混沌洗，可选崇高补满和上瓦尔 | 校准背包起止格、仓库通货页 |
| 模板 | 从剪贴板粘贴截图、保存并测试模板匹配 | 与实际游戏分辨率、UI 缩放一致的截图 |
| 标价补丁 | 将国服/国际服兜底行情写入客户端物品名称，支持安全恢复 | 国服客户端路径；写入时需退出游戏 |
| 游戏增强 | 视距调整、小地图全开与配色、环境去雾 | 国服客户端路径；写入时需退出游戏 |
| 设置 | 热键、延迟、后台输入、模板阈值及后台兼容性检测 | 修改后自动保存 |

自动化的共同能力包括：

- 解析简体中文物品文本中的稀有度、名称、词缀名称、效果文本和数值。
- 规则支持组内 AND / OR / 至少匹配 N 条，组间 AND / OR，以及数值比较。
- 花园和普通工艺默认使用 WGC 按窗口截图与后台定向输入；游戏可被其他窗口遮挡，但不能最小化。
- 普通工艺会在右键通货前核对中文名称与堆叠数量；洗地图会逐次核对通货名称。复制或位置异常时停止，不盲点。
- 默认 **F7** 开始、**F8** 停止；花园/普通工艺还会在达到最大次数、连续解析失败、模板丢失或词缀长期不变时停止。

## 运行要求

### 使用 portable 包

- Windows x64。
- 游戏使用**窗口或无边框窗口**，不要使用互斥全屏。
- 如果游戏以管理员身份运行，POE Tools 也需要使用相同权限级别；portable 包默认请求管理员权限。
- portable 包已内置客户端资源补丁辅助组件，不需要安装 Node.js 或 .NET SDK。

### 从源码运行

- Windows x64。
- Node.js 22.12+，建议使用当前 LTS 版本。
- .NET 8 SDK、PowerShell 和网络连接，用于构建 `PoeBundleTool` 及下载经 SHA-256 固定校验的 LibGGPK3 组件。

```powershell
cd <项目目录>
npm install
npm start
```

`npm start` 会依次构建客户端资源补丁辅助组件、Vue 前端和 Electron 主进程，然后启动桌面程序。开发模式使用 Vite 热更新：

```powershell
npm run dev
```

构建 Windows portable 包：

```powershell
npm run build:exe
```

输出位于 `release/`。

## 热键与页面作用域

- **F7**：只在「花园工艺」「普通工艺」或「洗地图」页启动当前页面的任务。
- **F8**：任意页面都可请求停止正在运行的工艺或洗地图任务。
- **F6**：仅在洗地图校准模式中捕获当前鼠标所在的背包格。
- 在「使用说明」「模板」「标价补丁」「游戏增强」和「设置」页按开始热键不会启动自动化。

开始/停止热键可在设置页修改。`F1`–`F24` 可以单独使用；字母或数字必须搭配 `Ctrl`、`Alt`、`Shift` 或 `Super`，避免全局占用普通输入。**F6 是洗地图校准保留键，不要将它配置为开始或停止热键。**热键注册失败时页面会提示。

## 模板与规则

### 模板截图

推荐直接在「模板」页粘贴：

1. 游戏内用 `Win+Shift+S` 截取按钮或装备格。
2. 回到 POE Tools，在非输入框区域按 `Ctrl+V`，或点击“从剪贴板粘贴”。
3. 选择保存目标，保存后点击“测试模板匹配”检查分数。

| 文件 | 用途 |
| --- | --- |
| `craft_button.png` | 花园工艺的执行按钮 |
| `item_slot.png` | 花园工艺槽或普通工艺的目标装备位置 |

截图时保持游戏分辨率和 UI 缩放与日常使用一致，只截稳定的核心文字/图标。普通工艺不使用通货图片：通货按仓库格坐标定位，再通过剪贴板核名。仓库中的 `currency_*.png` 仅供 `scripts/calibrate-stash.cjs` 做坐标标定。

### 词缀规则

- 条件可匹配词缀名称或效果文本。
- 空格、逗号或分号分隔的关键字表示“并且”；例如 `泥藓之 感电`。
- 竖线 `|` 表示“或者”；例如 `炼金的|业余者的|启蒙师的`。
- 数值算子支持 `>=`、`>`、`<=`、`<`、`=`；默认使用命中效果行的第一个数字。
- 每个规则组可选 AND、OR 或“至少匹配 N 条”，多个组之间也可选 AND / OR。

## 花园工艺

1. 在「模板」页准备 `craft_button.png` 和 `item_slot.png`，并测试匹配。
2. 在「花园工艺」页至少启用一条非空目标规则。
3. 在游戏园艺台中放入物品，并先选好要重复的工艺。
4. 点击顶部“开始花园”，或停留在该页面按 **F7**；按 **F8** 停止。

启动后程序只负责点击当前执行按钮、读取装备并判断规则，不会自动选择花园工艺，也不会判断生命力余量。

## 普通工艺

「普通工艺」是可编辑的多步骤通货流程：

1. 从分组中选择流程，或新建、复制现有流程。
2. 每步选择通货类型，按需设置动作前的稀有度、显式词缀数和规则，再设置动作后的判断条件。
3. 分别配置命中与未命中后的行为：下一步、重复、跳转到指定步骤、完成或停止。
4. 用上下移动按钮调整步骤顺序，保存流程。
5. 打开仓库「非绑定 / 通用」通货页，让目标装备和会用到的通货位于游戏客户区；点击“开始流程”或按 **F7**。

内置流程库当前包含 6 个“腰带重组”预设，以及一个“头盔·元素+生命”示例。预设只是起点，可以复制后修改；运行时配置写入 `config/workflows.json`。

普通流程的第一个动作始终只读取目标装备，不点击也不消耗通货。读取成功后会根据当前稀有度和词缀恢复流程位置。动作前条件不满足时不会使用通货；通货应用后的剪贴板读取若暂时失败，只会重读装备，不会重复施放同一枚通货。

通货按游戏窗口高度换算仓库格中心，并把相邻格作为候选。每次右键前都必须复制出正确中文名和堆叠数量，同时在本地记录余量。最后一枚可正常使用，下一次需要同类通货且找不到有效堆叠时会在点击前停止。

## 后台输入

后台输入只用于**花园工艺、普通工艺及其单次读装备功能**；洗地图仍会切换到游戏并移动实体鼠标。

启用后台输入时：

- WGC 按 HWND 获取游戏画面，其他窗口可以完全遮挡游戏；最小化不受支持。
- 鼠标移动和左右键消息只投递到游戏客户区，不移动实体鼠标，也不抢当前键盘焦点。
- 复制时会在目标线程确认 `Ctrl` 状态后发送 `C`，并保证释放按键；最终以剪贴板出现合法装备文本为成功标准。
- WGC 不可用时界面会显示 GDI 回退；被遮挡时 GDI 无法保证正确识别。

设置页提供三步“后台输入兼容性检测”：先标定目标装备，再用其他窗口遮挡游戏（不要最小化），依次执行安全复制和增强复制测试。检测不会点击鼠标，但会临时占用系统剪贴板。若环境不兼容，可关闭后台输入，退回需要游戏置前的前台模式。

## 洗地图

洗地图按背包第 1 排第 1 格到第 5 排第 12 格建立 5×12 网格，可选择实际处理的起止格（1–60）。本功能使用前台输入：开始前请手动确认游戏已置前且无遮挡，运行时不要移动/缩放窗口，也不要操作鼠标、键盘或剪贴板。

1. 游戏使用窗口/无边框模式，仓库停在「非绑定 / 通用」通货页，点金、重铸、混沌、崇高和瓦尔通货位于内置格位。
2. 点击“校准起始格”，把鼠标移到背包左上格后按 **F6**；再校准右下格。校准结果会持久化。
3. 选择点金洗或混沌洗。点金洗执行“点金 → 判断 → 未命中则重铸”；混沌洗会先把非稀有地图升为稀有，再循环使用混沌石。
4. 按需启用“崇高E满”和“上瓦尔”。它们只在过滤命中后执行。
5. 编辑过滤文本，可先用“试读当前格”和“测试过滤”验证，再点击“开始洗图”或在本页按 **F7**。

> 当前版本不会验证选区内的非空物品一定是地图。开始前必须确保所选格位只放待处理地图，不要混入装备、通货或其他贵重物品；也不要与花园/普通工艺同时运行。

过滤语义：

- 空行和 `//` 开头的行会被忽略。
- 第一个 `##` 前是默认区，其中所有条件都必须满足。
- 每个 `##` / `###` 后是一个判断区；任一判断区全部满足即可。
- `!词条` 表示该词条不能出现。
- `词条 >= 100` 进行数值比较，支持 `>`、`<`、`>=`、`<=`、`==`、`!=`。

```text
// 默认区：全部满足
物品数量 > 100
!格挡
!再生

## 判断区 1
塑界者

## 判断区 2
贤主
```

页面设置约 600 ms 防抖后自动写入 `config/mapwasher.json`，校准会立即保存。运行状态、成功/空格/失败/停止计数和最近日志会显示在页面中。洗地图读取 `settings.json` 中的动作延迟、剪贴板超时和窗口标题关键字；其中后两项目前属于高级配置，需要直接编辑 JSON。

点金洗和混沌洗每格固定最多尝试 200 次，崇高最多使用 3 次，不读取通用“最大次数”。“崇高E满”按复制文本中的有效行数估算词缀数量，并非完整的显式词缀解析；使用前请先通过试读确认目标地图文本符合预期。

## 国服客户端标价补丁

在「标价补丁」页：

1. 确认客户端目录。可留空自动检测 WeGame 国服客户端，也可手动选择；补丁已应用或有等待操作时路径会锁定。
2. 选择标价格式。默认易刷模式生成 `物品名[1.2d]`；来源标识模式用 `·` 标记国服价格、用 `⁙` 标记 poe.ninja 国际服兜底价。切换选项后需要重新应用。
3. 点击“应用标价补丁”。游戏运行中会进入等待状态，退出游戏后自动继续。

行情优先级为：**易刷当季国服价表 → `poecurrency.top` 国服备用行情的最新买 1 → `poe.ninja` 当前赛季行情**。匹配综合中文名、英文名和内部 Id，覆盖基础物品、唯一物品、技能宝石、神庙房间和可捕捉野兽。高于一枚神圣石的 c 价按同一来源汇率换算为 d；同名变体选择样本量最高的代表价。价格仅供参考。

首次接管一个客户端版本时，程序会创建不可覆盖的校验基线，保存 Bundle 索引、已有自定义 Bundle，以及 `BaseItemTypes`、`Words`、`UniqueStashLayout`、技能宝石、神庙房间和野兽相关资源。备份记录大小与 SHA-256；补丁先在临时副本中生成并回读，再通过可回滚的同盘事务提交，索引最后生效。每次从基线重建名称，不会在旧价格后重复叠加。

“立即更新价格”“取消补丁 / 恢复原版”和闲置自动更新在游戏运行时都会排队。自动更新约每小时检查一次，并沿用客户端当前已经应用的格式。检测到客户端版本变化时会建立新基线，旧基线不会被覆盖。

> **谨慎使用“重置基线备份”：** 它不会下载或恢复官方原版，而是把当前客户端资源原样设为以后恢复的起点。若当前仍含价格后缀或第三方修改，今后的恢复也会回到该状态。旧基线目录仍会保留。

## 国服客户端增强

「游戏增强」页提供三项可独立启用的客户端资源修改：

- **视距调整**：`1.5x / 2x / 2.5x / 3x / 3.5x / 4x / 5x`。
- **小地图全开**：渲染整张地图地形线，可选默认、紫色、橙色或蓝色。
- **环境去雾**：移除场景距离雾与高度雾，不修改小地图探索迷雾。

开关、倍率和颜色只保存设置；点击“应用”后才写入客户端。增强功能优先沿用标价补丁页保存的客户端目录，未指定时自动检测。游戏运行中应用或恢复会排队，退出后执行；页面显示完成后再启动游戏。

首次应用会为以下四个目标资源保存 original 与 clean 副本并记录 SHA-256：

- `metadata/characters/character.ot`
- `shaders/minimap_visibility_pixel.hlsl`
- `shaders/minimap_blending_pixel.hlsl`
- `shaders/renderer/fog.ffx`

“恢复首次修改前资源”会回到 POE Tools 首次接管前的字节内容。若易刷或其他工具已经修改相同资源，建议先用原工具还原，再由 POE Tools 接管；检测到已应用资源被外部改动时程序会拒绝盲目覆盖。

“重置增强基线备份”同样是把当前四个资源设为新的恢复起点，并不等于恢复官方原版。标价补丁与游戏增强共用串行写锁，各自只替换目标资源，可以同时使用。

## 设置与数据目录

设置页可编辑最大次数、动作延迟、工艺等待、后台输入、模板阈值和开始/停止热键，修改后自动写入 `settings.json`。剪贴板超时、轮询间隔和窗口标题关键字目前需要直接编辑配置文件。

运行时数据位置：

| 运行方式 | 数据根目录 |
| --- | --- |
| 从源码运行 | 项目根目录 |
| portable / 打包版 | `%APPDATA%\PoeCrafting` |

可在设置页点击“打开数据目录”。主要内容如下：

- `config/settings.json` — 延迟、热键、后台输入、窗口标题和模板阈值。
- `config/rules.json` — 花园工艺目标规则。
- `config/workflows.json` — 普通工艺流程库；旧 `workflow.json` 只会导入一次并改名归档。
- `config/mapwasher.json` — 洗地图设置、格位校准和过滤文本。
- `config/price-patch.json` — 标价路径、格式、自动更新和应用状态。
- `config/client-enhancements.json` — 视距、小地图、去雾和应用状态。
- `assets/templates/` — 用户模板。
- `price-patch/`、`client-enhancements/` — 校验基线、事务标记和临时文件。
- `logs/` — 打包版运行日志；源码开发日志位于 `.electron-data/logs/`。

仓库中的 `config/defaults/` 是新用户的出厂配置，不应写入个人配方。打包版首次运行会把缺失的默认文件复制到用户数据目录；升级不会覆盖已有配置。

## 限制与安全边界

- 仅支持简体中文物品文本和 Windows x64。
- 游戏必须处于窗口或无边框模式；后台识别不支持最小化。
- 自动化会清空并覆盖系统剪贴板，结束后不会恢复原内容；运行期间不要使用剪贴板。
- 洗地图使用前台鼠标与键盘输入，不支持遮挡运行，也不会验证格内物品类别。
- 当前界面没有完整阻止普通/花园工艺与洗地图并行；切换任务前必须先确认上一项已经停止。
- 普通工艺依赖内置的「非绑定 / 通用」通货页格位；游戏更新改变布局后应先验证坐标。
